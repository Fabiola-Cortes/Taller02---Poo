## **Descripción del Proyecto**

El proyecto consiste en un sistema desarrollado en Java para llevar la cuenta de los choripanes y terremotos consumidos en La Fonda del Papu. El sistema toma la lista de participantes (`Participantes.txt`) y los consumos registrados (`Consumido.txt`) para mostrar los registros y calcular métricas como las kcal consumidas y los días ebrio por usuario. También permite agregar, editar y eliminar consumos, guardando los cambios en el archivo.

```
Estructura del Repositorio

.
├── README.md
├── Participantes.txt
├── Consumido.txt
└── src/
    └── TallerPoo/
        ├── TallerDos.java
        ├── Fonda.java
        ├── Choripan.java
        └── Terremoto.java

```

## **Instrucciones de Ejecución**

1. Clonar el repositorio: `git clone https://github.com/Fabiola-Cortes/Taller02---Poo.git`
2. Abrir el proyecto en Eclipse (o cualquier IDE de Java compatible).
3. Asegurarse de que los archivos de datos (`Participantes.txt` y `Consumido.txt`) estén ubicados en la carpeta raíz del proyecto.
4. Compilar y ejecutar la clase principal `TallerDos.java`.
